# Bersz Records — Portal de Lanzamientos

Portal estático de Bersz Records publicado desde GitHub Pages.

## Archivos principales

- `index.html`: pantalla de acceso y solicitud de ingreso.
- `portal-demo.html`: interfaz de demostración del portal.
- `bersz-logo.png`, `bersz-full.png`, `bersz-pill.png`: recursos de marca usados por las páginas.
- `favicon.png`: icono del navegador.
- `CNAME`: dominio personalizado de GitHub Pages.
- `LEEME.txt`: notas de uso, funciones y límites actuales de la demo.

## Publicación

GitHub Pages debe publicar la rama `main` desde la carpeta raíz (`/root`). Mantén los archivos de las páginas y las imágenes en esta misma raíz, salvo que actualices también las rutas en el código.

## Importante

La interfaz de demostración guarda datos localmente en el navegador. No debe tratarse como un sistema de producción ni como control de acceso seguro. Revisa `LEEME.txt` antes de cambiar el flujo de autenticación o el backend.
